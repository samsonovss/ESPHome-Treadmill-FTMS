# MCP-сервер: ИИ-агенты

[English version](MCP.md) · [Назад к README](../README.ru.md)

На дорожке работает небольшой сервер [Model Context Protocol](https://modelcontextprotocol.io) по адресу `http://<дорожка>/mcp`. Claude и другие MCP-клиенты могут читать ваши тренировки и сохранять для вас программы.

**Безопасность заложена в устройство:** ни один инструмент не может запустить тренировку или сдвинуть полотно. `save_program` только сохраняет проверенный файл программы; запускаете её вы сами, на дорожке или на веб-странице. Инструменты истории и запись программ отклоняются, пока идёт тренировка.

> [!WARNING]
> Авторизации нет. Открывайте `/mcp` только в доверенной домашней сети.

## Подключение

На веб-странице дорожки в *Настройки → Агенты (MCP)* показаны эти же фрагменты с уже подставленным адресом вашей платы.

**Claude Code:**

```sh
claude mcp add --transport http treadmill http://treadmill.local/mcp
```

**Claude Desktop и другие клиенты, которые умеют только stdio** (через [`mcp-remote`](https://www.npmjs.com/package/mcp-remote)):

```json
{
  "mcpServers": {
    "treadmill": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "http://treadmill.local/mcp", "--allow-http"]
    }
  }
}
```

Если компьютер не разрешает имена `.local`, укажите вместо `treadmill.local` IP-адрес.

## Инструменты

| Инструмент | Что делает |
|---|---|
| `get_status` | Состояние записи (`idle` / `recording` / `finalizing`) и заполненность хранилища |
| `get_live` | Последний отсчёт текущей или последней тренировки: пульс, скорость, наклон, дистанция, калории, зона |
| `list_workouts` | Страница ID сохранённых тренировок (`after`, `limit` ≤ 20); продолжение через `next` |
| `get_workout_summary` | Итоги одной тренировки: дистанция, время, зоны, нагрузка (`trimp`), 5-минутные блоки |
| `list_programs` | ID программ, сохранённых на плате |
| `get_program` | Полный JSON одной программы |
| `save_program` | Сохранить программу (тот же ID перезаписывается); только при остановленном полотне |
| `delete_program` | Удалить программу; только при остановленном полотне; без возврата |

В описании `save_program`, которое сервер отдаёт агенту, есть полный формат программы, лимиты и рекомендации по пульсовым зонам, поэтому агент может планировать разумные тренировки без дополнительных инструкций.

## Формат программы (кратко)

```json
{
  "version": 1,
  "id": "p0123456789abcdef",
  "name": "Tempo 30",
  "schema_units": {"duration": "s", "speed": "km/h", "incline": "level"},
  "blocks": [
    {"repeat": 1, "steps": [{"duration": 300, "zone": 1, "incline": 0}]},
    {"repeat": 4, "steps": [{"duration": 180, "speed": 10.0, "incline": 2},
                            {"duration": 120, "speed": 7.0, "incline": 0}]},
    {"repeat": 1, "steps": [{"duration": 300, "zone": 1, "incline": 0}]}
  ]
}
```

- `id`: `p` + 16 шестнадцатеричных цифр в нижнем регистре;
- у шага есть `speed` (км/ч) **или** `zone` (1-5: тогда скорость подбирает пульсовый регулятор дорожки);
- необязательные `goal`, `plan` и `day` (`YYYY-MM-DD`) собирают программы в недельный план на странице;
- лимиты: до 64 блоков × 64 шага, всего 4 часа, 8 КБ; скорость и наклон должны попадать в сетку min/max/шаг платы. Чтобы программу можно было запустить со страницы, держите её в пределах ~25 шагов после раскрытия повторов.

## Протокол

JSON-RPC 2.0 поверх HTTP `POST /mcp`, без состояния (без сессий и SSE). Методы: `initialize`, `ping`, `tools/list`, `tools/call`. Версии протокола `2024-11-05`, `2025-03-26` и `2025-06-18`. `GET /mcp` возвращает 405.

```sh
curl -s http://treadmill.local/mcp -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"get_status","arguments":{}}}'
```
