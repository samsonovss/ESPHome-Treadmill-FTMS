# Установка

[English version](INSTALL.md) · [Назад к README](../README.ru.md)

## 1. Первая прошивка: только по USB

Нужна ESP32-S3 с 16 МБ флеш-памяти и 8 МБ octal PSRAM (`N16R8`). У прошивки своя разметка флеш-памяти: 16 МБ, отдельный раздел под архив тренировок. Плату со старой сборкой или чужой прошивкой **нельзя переделать по Wi-Fi**: первый раз прошиваем по USB. Все следующие обновления идут по Wi-Fi.

1. Установите [ESPHome](https://esphome.io/guides/getting_started_hassio/) (дополнение Home Assistant или `pip install esphome`).
2. Скопируйте всю папку [`esphome/`](../esphome/) в папку конфигураций ESPHome. `packages/`, `components/` и файлы `*.h` должны лежать рядом с yaml-файлами.
3. Подключите ESP32-S3 к компьютеру кабелем USB (родной USB-порт).
4. В панели ESPHome откройте **`treadmill-public.yaml`** и выберите *Install → Plug into this computer* (или `esphome run treadmill-public.yaml`).

В публичной сборке нет секретов и пароля Wi-Fi, она подходит всем как есть. Если хотите, чтобы свой Wi-Fi, ключ API и пароль OTA были внутри прошивки, используйте приватную сборку, см. [сборку из исходников](BUILD.ru.md).

## 2. Настройка Wi-Fi

1. После прошивки плата поднимет точку доступа **`Treadmill Setup`** (открытая, без пароля).
2. Подключитесь к ней с телефона или ноутбука. Страница настройки откроется сама; если нет — зайдите на `http://192.168.4.1`.
3. Выберите домашнюю сеть, введите пароль и сохраните. Плата перезагрузится и подключится к вашей сети.

Настройки Wi-Fi хранятся во флеш-памяти платы и **сохраняются при обновлениях**. Пока плата в режиме настройки, Bluetooth выключен, чтобы точка доступа работала стабильно. Подождите около 30 секунд после включения.

## 3. Откройте веб-интерфейс

Откройте в браузере `http://treadmill.local` или IP-адрес устройства `treadmill`, который показывает роутер. Интерфейс работает на телефоне, планшете и компьютере.

## 4. Первые проверки (без человека на полотне)

- **Стоп** останавливает ленту;
- минимальная скорость мягкая;
- наклон возвращается в ноль;
- пределы скорости и наклона соответствуют вашей дорожке.

Затем в *Настройках* заполните профиль (возраст, вес, максимальный пульс): от него зависят пульсовые зоны и калории.

## 5. Пульсометр

*Настройки → Пульсометр*: наденьте пульсометр, запустите поиск, выберите свой. Выбор хранится на плате и восстанавливается после перезагрузок и обновлений.

## 6. Обновления

В *Настройки → Система*:

- **Прошивка ESP** — прошивка дорожки. Плата проверяет GitHub при включении и каждые 6 часов; кнопка **Проверить** — проверить сейчас. Когда вышла новая версия, появляется кнопка **Обновить до v…** и синий значок микросхемы в шапке. Лента должна стоять. Плата скачает прошивку с GitHub, установит и перезагрузится за 1–2 минуты. Wi-Fi, история и пульсометр сохраняются.
- **Прошивка дисплея** — дисплей Nextion. Когда вышла новая версия, в шапке появляется красный значок монитора, а в строке — **Обновить до v…**. Плата скачает `.tft` и запишет его в дисплей, это несколько минут. Не отключайте питание.

Прошивки выходят как **pre-release** (бета) на странице [Releases](https://github.com/samsonovss/ESPHome-Treadmill-FTMS/releases).

## Home Assistant (необязательно)

Дорожка — обычное устройство ESPHome: Home Assistant сам найдёт её в сети (*Настройки → Устройства и службы*). В публичной сборке нет ключа шифрования API, поэтому она добавляется без ключа. Если нужно шифрование, используйте приватную сборку.

## Если что-то не так

| Проблема | Что делать |
|---|---|
| Нет точки `Treadmill Setup` | Подождите ~30 с после включения. Если плата уже знает Wi-Fi-сеть, она сначала пробует её; точка появится, только если подключиться не удалось (примерно через минуту). |
| Не открывается `treadmill.local` | Откройте по IP из роутера: некоторые сети и Android не понимают имена `.local`. |
| Кнопка обновления ничего не делает | Сначала остановите ленту: во время работы обновление запрещено. |
| Обновление по Wi-Fi не проходит сразу после старой сборки | На плате ещё старая разметка памяти: один раз прошейте по USB (шаг 1). |
