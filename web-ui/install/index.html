Install the treadmill firmware

ESPHome Treadmill FTMS · version … · GitHub

Your browser cannot flash over USB. Use Chrome or Edge on a computer. Open this page over HTTPS.

Before you start

  1. Board: ESP32-S3 with 16 MB flash and 8 MB octal PSRAM (N16R8).
  2. Connect it to this computer with a USB data cable. If no port shows up, hold BOOT, press RESET, release BOOT.
  3. The installer offers to erase the board first. Say yes for a board with other firmware; saved workouts are lost.

After the install

  1. Join the Treadmill Setup Wi-Fi hotspot and pick your home network.
  2. Open http://treadmill.local (or the IP from your router).
  3. From now on updates come over Wi-Fi: Settings → System, one click.

Prefer a file? Download treadmill-fw-…factory.bin from the releases and flash it with ESPHome Web.

Установка прошивки дорожки

Версия …. Кнопка «Connect and install» выше.

Перед началом

  1. Плата: ESP32-S3 с 16 МБ флеш-памяти и 8 МБ octal PSRAM (N16R8).
  2. Подключите её к компьютеру USB-кабелем с передачей данных. Если порт не появился, зажмите BOOT, нажмите RESET, отпустите BOOT.
  3. Установщик предложит сначала стереть плату. Для платы с другой прошивкой соглашайтесь; сохранённые тренировки при этом пропадут.
  4. Нужен Chrome или Edge на компьютере.

После установки

  1. Подключитесь к точке доступа Treadmill Setup и выберите домашнюю сеть.
  2. Откройте http://treadmill.local (или IP из роутера).
  3. Дальше обновления идут по Wi-Fi: Настройки → Система, одна кнопка.

Нужен файл? Скачайте treadmill-fw-…factory.bin из релизов и прошейте через ESPHome Web.
